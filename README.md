# Data Deletion Audit Agent

## Overview
The Data Deletion Audit Agent is a project designed to verify whether customer data has been completely deleted across different systems after a deletion request.

## Problem Statement
Even when a data deletion request is marked as complete, customer information may still remain in databases, backups, logs, or other connected systems.

## Objectives
- Track customer data deletion requests.
- Audit deletion status across multiple data sources.
- Identify leftover customer data.
- Generate an audit report showing deletion status.

## Proposed Solution
Build an audit agent that checks deletion records, detects possible leftover data, and reports incomplete deletions.
